HAPPINESS SIGNATURE — starter website

HOW TO OPEN
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. An internet connection is needed for the temporary photos and Google Fonts.

BEFORE PUBLISHING
- Replace the temporary inspiration photos with your mum's real product and gele-service photos.
- Add real product names, prices, sizes, availability, and business information.
- In index.html, find `const WHATSAPP_NUMBER = "";` and add her WhatsApp Business number using country code and digits only, without + or spaces (example format: 2348012345678).
- Test the website on a phone and computer.

This is a front-end starter. It does not yet include a real database, shopping cart, online payments, inventory management, or a confirmed booking system. The floating orb is a lightweight 3D-inspired CSS decoration, not a full 3D model; a Spline/Three.js scene can be added in a later step.
